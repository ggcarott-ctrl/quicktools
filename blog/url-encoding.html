URL Encoding: Kenapa URL Harus di-Encode?

17 Agustus 2026 • 4 menit baca

Apa Itu URL Encoding?

URL encoding (atau percent encoding) adalah metode mengubah karakter yang tidak aman di URL menjadi format yang valid. Contoh: spasi menjadi %20, huruf Indonesia menjadi %C3%A9.

Contoh

Asli:  https://contoh.com/cari?query=halo dunia
Encode: https://contoh.com/cari?query=halo%20dunia

Kapan Perlu URL Encode?

  • Query parameter mengandung spasi atau karakter khusus
  • Mengirim data form melalui URL
  • API membutuhkan URL-encoded parameters
  • Membangun URL secara dinamis
