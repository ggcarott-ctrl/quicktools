Base64 Adalah...

Base64 adalah metode encoding yang mengubah data biner (binary) menjadi teks ASCII yang aman untuk ditransfer melalui sistem yang hanya mendukung teks, seperti email dan URL.

Kapan Base64 Dipakai?

  • Email - Melampirkan file gambar/dokumen dalam email
  • Data URI - Menyematkan gambar langsung di HTML/CSS
  • API - Transfer data binary melalui REST API
  • Autentikasi - HTTP Basic Authentication menggunakan Base64

Contoh

Teks: Hello World → Base64: SGVsbG8gV29ybGQ=
