Apa Itu Markdown?

Markdown adalah bahasa penanda ringan untuk membuat teks menjadi formatted text (bold, italic, heading, dll) dengan syntax yang sangat sederhana.

Syntax Dasar Markdown

  • # Heading 1 - Heading besar
  • ## Heading 2 - Heading sedang
  • **bold** - Teks tebal
  • *italic* - Teks miring
  • `code` - Inline code
  • - item - List item
  • [link](url) - Hyperlink

Dimana Markdown Dipakai?

  • GitHub (README.md)
  • Notion, Obsidian, Bear
  • Reddit, Discord
  • Dokumentasi API
  • Blog dan CMS
